# ☕ Coffee Shop Performance Overview Dashboard

## 📌 Project Description
This project presents a Coffee Shop Performance Overview Dashboard created to analyze sales, orders, profit, and customer trends. The dashboard provides a clear and interactive summary of business performance to support data-driven decision-making.

## 🎯 Objectives
- Analyze total orders, items sold, sales, and net profit
- Understand revenue distribution by product category
- Track weekday and monthly sales trends
- Compare yearly revenue performance
- Identify top-performing categories and cities

## 📊 Tools & Technologies Used
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Data Cleaning & Data Analysis  
- Dashboard Design & Visualization  

## 🗂 Dataset Details
The dataset contains the following fields:
- Order ID  
- Order Date  
- Product Category  
- Product Name  
- Quantity Sold  
- Revenue  
- Profit  
- City  

## 📈 Dashboard Features
- **KPIs:** Total Orders, Items Sold, Total Sales, Net Profit  
- **Revenue by Category:** Cold Drinks, Specialty Drinks, Tea Beverages, Desserts  
- **Orders by Weekdays:** Sales trend from Monday to Sunday  
- **Yearly Revenue Comparison:** 2022 vs 2023  
- **Monthly Revenue Trend:** Jan to Dec analysis  
- **Revenue Share by City:** Los Angeles, Chicago, New York, Seattle, Austin  
- **Monthly Revenue vs Profit Comparison**

## 🧹 Data Cleaning Steps
- Removed duplicate records  
- Handled missing values  
- Corrected date and numeric formats  
- Standardized category and city names  

## 🔍 Key Insights
- Cold Drinks generate the highest revenue  
- Sales peak during specific weekdays and months  
- Certain cities contribute significantly to total revenue  
- Profit trends closely follow revenue growth patterns  

## 📌 Conclusion
The Coffee Shop Performance Dashboard offers a comprehensive view of sales and profitability. It helps stakeholders monitor performance, identify trends, and optimize business strategies effectively.
